# NMM 光影预演室

一个可在本机离线运行的 NMM（非金属金属）高光预演原型。基础手绘模式不依赖 AI；自动模式使用本地视觉模型完成主体分割与形体估算，照片不会发送到云端。

## 立即运行

基础版可以直接执行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

要使用本地 AI 自动分析，请先安装 [uv](https://docs.astral.sh/uv/)，然后执行：

```bash
uv venv --python 3.12 .venv
UV_CACHE_DIR=/tmp/nmm-sim-uv-cache uv pip install --python .venv/bin/python \
  torch torchvision transformers fastapi uvicorn python-multipart pillow numpy scipy modelscope
UV_CACHE_DIR=/tmp/nmm-sim-uv-cache uv pip install --python .venv/bin/python --no-deps \
  'git+https://github.com/ByteDance-Seed/depth-anything-3.git@3d835ec1a5802d64a8b8b15f817a1ab54809bfe4'
UV_CACHE_DIR=/tmp/nmm-sim-uv-cache uv pip install --python .venv/bin/python \
  'numpy<2' omegaconf einops e3nn opencv-python-headless moviepy==1.0.3 \
  imageio trimesh plyfile pillow-heif addict pycolmap matplotlib
.venv/bin/python scripts/patch_da3_macos.py
.venv/bin/python scripts/download_models.py sam3 da3
PYTORCH_ENABLE_MPS_FALLBACK=1 MPLCONFIGDIR=/tmp/nmm-sim-matplotlib \
  .venv/bin/python scripts/run_local.py
```

再打开 <http://localhost:4173>。导入照片后程序会自动开始生成 NMM 指引。

## 使用方式

1. 导入自己的模型照片；程序会立即自动识别主体、估算深度并生成 NMM 指引。
2. 如果主体缺失，直接点击左侧“补充识别区域”并在遗漏部位拖出矩形。
3. 常用区提供“光影强度”“金属光滑度”“光影平滑”、金属材质和艺术色调；其他光照参数默认使用推荐值，需要时可展开“高级设置”。
4. 拖动画面中的太阳可改变主光方向。
5. 拖动主画面右侧的 Zoom 滑条，以当前视口中心放大；停止拖动后程序会自动按 `1008 px` 重新计算深度和光影。缩回 `1×` 即恢复整体视图。
6. 画布右侧提供“原图”和“光影”对比开关；最终可直接导出当前二维参考图。

基础模式的计算全部在浏览器内完成。自动模式会把照片发给同一台电脑上的本地服务（`127.0.0.1`）处理，不会上传到互联网。

## 当前算法

- AI 模式从深度与相机内参生成逐像素三维法线。
- 使用 Lambert 漫反射、Blinn–Phong 高光和视角边缘光计算明暗。
- 使用两个随主光变化的虚拟环境光瓣生成次反光和第三层窄反射。
- 使用主光、受限自动补光和微结构掠射细节光组成艺术布光；各灯按取强和限幅方式合成，不直接累加洗白画面。
- 将连续结果压缩为推荐的 7 阶 NMM 手绘色阶，图例会显示实际生成的全部颜色。

这是一款用户辅助工具，并不会从单张照片自动恢复真实三维结构。表面类型和选区越准确，预演越有参考价值。

## AI 自动分析模式

- `facebook/sam3`：根据文字提示找出并分割微缩模型。
- `depth-anything/DA3-LARGE-1.1`：估算单目深度与相机内参。
- 本项目固定着色器：将法线转换为可调的 NMM 主高光、次反光和第三层反射。

程序不会把整个模型近似成一种基础形状。后端会用相机内参把每个深度像素反投影为三维点，再从相邻三维点的切线计算逐像素法线。因此肩甲、剑身、甲片等不同局部会在同一张图上使用各自的表面方向；球面、圆柱和平面等手工近似模式已从界面移除。

SAM 3 支持用户框提示。自动识别不完整时，框选区域会作为正向目标重新分割，并与原主体蒙版取并集；矩形本身不会被直接填入主体。最多可累计 8 个补充区域。

自动分析还会从轮廓和三维曲率生成白底黑线稿，去除原照片的颜色与涂装质感。NMM 色阶绘制在线稿之下，并保留黑色结构线。法线采用多尺度规则化，避免把单目深度的微小噪声放大成碎裂的高光色块。

“光影平滑”放在常用区，可在 `0–24 px` 之间实时调整；默认值为经过测试的 `4 px`，在保留小型甲片和雕刻细节的同时压制单目深度噪声。它只作用于用于绘画的法线，不会模糊最终导出的黑色结构线。

画布默认显示最终指引。一次反射使用所选“材质 × 色调”组合并自动量化为推荐的 7 阶；二次反射固定标为青蓝色，三次反射固定标为暖橙色。当前提供白银、不锈钢、铝、黄金、红铜、青铜和黑钢 7 种材质，以及原色、红、黄、绿、蓝、紫、黑 7 种艺术色调，共 49 种组合。切换材质还会带入对应的推荐光滑度。

深度精度固定为 `1008 px`，这是这台 24 GB Apple Silicon 机器实测稳定的最高实用档；真实高分辨率照片首次运行可能需要 2–3 分钟。后端的法线规则化也已减弱，不会再把新增深度细节大面积抹平。

深度推理会在 SAM 3 分割后自动聚焦主体：保留一圈上下文并裁掉无关背景，把同一档位的深度采样尽量集中到微缩模型上。若主体已经占满画面则自动使用全图。裁剪后的相机内参会转换回原图坐标，分析完成时会显示本次主体有效采样倍率。

整体分析完成后还可使用右侧 Zoom 滑条。程序以当前视口中心裁切原始照片与主体蒙版，再以最长边 `1008 px` 重新运行深度估算；它不会放大既有的低分辨率深度图。结果会直接替换主画布，并继续使用同一套自动布光。

拖动滑条或在画面上滚动时会先即时预览；停止操作约 `0.8` 秒后，只对最终中心视口提交一次推理，避免每一个滑条事件都排队运行模型。缩回 `1×` 会恢复缓存的整体结果，无需重复推理。

Zoom 推理会同时生成两套法线：平滑的整体法线负责大曲面，轻度规则化的微结构法线保留局部深度中的铆钉、接缝与浅浮雕。细节尺度与微结构融合强度默认采用经过测试的 `4 px / 28%` 推荐值，仅在 Zoom 结果中启用；需要时可在“高级设置”中调整。

右侧默认采用平衡的艺术布光：自动补光位于主光对侧并限制在非纯白色阶；细节光采用低角度掠射方向，只响应整体法线与微结构法线之间的差异，因此只在 Zoom 后启用。当前推荐值为 `28%` 补光与 `35%` 细节光；“高级设置”保留主光、均衡、细节预设以及各项专业参数。

界面只保留一个二维最终预览，不再初始化 WebGL 3D 灯光渲染。“原图”按钮用于切换照片纹理重着色，“光影”按钮可完全关闭 NMM 着色并显示未经处理的原照片，便于即时前后对比。

AI 推理期间，导入和补选区域会临时锁定；灯光、材质、原图显隐与导出仍可操作。同一浏览器中的多个页面共享一把推理锁，完成后还会保留短暂的显存冷却时间，避免连续请求同时进入 Apple MPS。

模型只在本机运行。SAM 3 的许可证在模型平台标为 `other`，商业发布前必须单独审核 Meta 的模型条款。

在 24 GB Apple Silicon Mac 上，两个模型会顺序装载并在每一步后同步、释放，以降低峰值内存。后端还会拒绝并行推理请求，避免多个 Metal 命令流互相冲突。MPS 不可用时会自动回退到 CPU，但速度会明显降低。模型默认从 ModelScope 的官方组织镜像下载，断点续传由 ModelScope 客户端处理。

## 照片重着色

“原图”采用照片材质重着色，而不是简单叠加半透明色块。程序先提取照片的局部高频明暗，再用计算得到的 NMM 色阶替换主体颜色，因此划痕、接缝和表面颗粒仍会保留，看起来更接近颜料画在模型表面。表面光滑度还会同时改变高光宽度、峰值亮度以及二、三次反射的集中程度。
