# 深度与点云精度提升记录

更新日期：2026-09-19

## 当前结论

当前默认的 `1008 px` 是 24 GB Apple Silicon 设备上已经完成真实照片端到端验证的最高实用档，不是 Depth Anything 3 或点云重建的理论最高精度。

当前产品界面已经取消 504/756/1008 多档选择，固定使用 `1008 px` 最高实用精度。较低档位只保留在历史测试记录中，不再暴露给用户。

当前处理链路包含三个不同的精度层级：

1. Depth Anything 3 Large 使用最长边 `1008 px` 推理。例如 `1280×1706` 的照片，实际深度采样大约为 `756×1008`，之后再插值回原图尺寸；插值不会产生新的几何信息。
2. 后端使用浮点深度和相机内参恢复逐像素法线，并进行轻度双边/高斯规则化。该结果直接决定 2D NMM 指引精度。
3. 浏览器中的 2.5D 预览目前使用最长边约 `384` 个网格点和 8-bit 深度图。它是单张照片的可见表面网格，不是包含背面与遮挡面的完整三维点云。

因此，“提高 3D 网格密度”和“提高 NMM 指引精度”不是同一件事。前者主要改善预览的平滑程度；后者必须改善模型输出的有效深度信息和法线质量。

## 已讨论的提升方案

按预期收益排序：

### 1. 主体裁剪后高分辨率推理

根据分割蒙版提取主体包围框，在保留少量上下文的情况下，把主体裁剪区域缩放到 `1008` 或 `1260 px` 后重新估算深度，再映射回全图。

当主体只占原图一部分时，这种方法可以显著增加模型主体上的有效采样密度，显存压力通常低于直接对整张照片使用 `1512 px`。

**状态：已于 2026-09-19 实现。** 当前会在 SAM 3 分割完成后，为主体包围框增加 14% 上下文，再把该区域送入 DA3。若有效线性采样提升不足 8%，程序自动保留全图推理。裁剪深度和相机内参会映射回原图坐标；界面在完成后显示本次主体有效线性采样倍率。内置圆盾端到端测试为 `1.66×`；历史真实微缩模型蒙版统计约为 `1.08×–1.40×`，主体已占满画面的照片保持 `1.00×` 全图推理。

### 2. 基于 Zoom 的局部高分辨率精修

**状态：已于 2026-09-19 实现第二阶段。** 完成整体分析后，用户可以框选任意矩形区域，或在主画布上滚动调整 Zoom 视口。程序会直接把当前层级的照片裁剪送入 DA3，以最长边 `1008 px` 重新估算，而不是先把已有的低分辨率深度图插值放大。结果直接成为新的主画布，因此灯光、色阶、金属色调、表面光滑度、光影平滑和反射设置天然共用同一套渲染链路。

Zoom 视图刻意不把局部深度强行拼回全图，避免不同裁剪之间的深度尺度与偏移造成接缝。各级结果会缓存在浏览器内存中，Zoom out 直接恢复上一级，不重新推理。滚轮停止约 `0.9` 秒后只提交最终视口，避免连续滚动产生推理队列。内置圆盾测试中，`251×278` 的框选区域输出为 `910×1008`，有效线性采样提升约 `3.63×`；更小的正方形测试曾达到约 `5.57×`。

Zoom 结果现在额外保留一套微结构法线：它直接从 DA3 的局部原始深度生成，只做约 `0.28 px` 的法线去噪，与负责整体形状的平滑法线分开保存。前端可按 `1–12 px` 细节尺度过滤，再以 `0–100%` 强度融合进灯光计算。默认值为 `4 px / 28%`；过高强度会暴露单目深度噪声，因此该功能保持可调而不直接替换整体法线。

### 3. 全局深度与局部精修融合

保留整图低频深度作为整体形状，再对头部、武器、甲片等主体区域进行重叠分块推理。局部结果不能直接拼接，需要完成尺度、偏移和边缘过渡对齐，只把可靠的高频残差融合回全局深度。

用户补充框选区域可以复用为局部深度精修区域，而不仅用于补充分割。

### 4. 增加实验性推理档位

- `1260 px`：真实 `1536×2048` 微缩模型照片压力测试超过 6 分钟仍未完成，已主动停止；当前机器上不加入正式界面。
- `1512 px`：只作为压力测试，不建议直接设为默认值。

相对 `1008 px`，`1260 px` 的输入像素约增加 56%，`1512 px` 约增加 125%。实际耗时和显存可能增长得更快。压力测试后产品已固定为 `1008 px`，不再提供较低或更高的用户可选档位。

### 5. RGB 边缘引导的深度上采样

使用原图结构边缘、主体蒙版和低分辨率深度共同引导上采样，使铠甲边缘、武器轮廓等位置更清晰。需要限制纹理泄漏，避免把原模型的涂装花纹错误解释为几何凹凸。

### 6. 提高 2.5D 预览精度

- 深度传输从 8-bit PNG 改为 16-bit 或浮点二进制。
- 预览网格最长边从约 `384` 提高到 `512/640`。
- 优先在轮廓和高曲率区域自适应加密，而不是平均增加所有顶点。
- 保留轮廓深度压平，避免主体边缘产生尖刺。

这项主要改善 3D 观察体验；后端 NMM 当前已经使用浮点深度计算，不会因为预览仍为 8-bit 而降低最终 2D 指引精度。

### 7. 平滑参数与细节的平衡

进一步减弱法线平滑可以显示更多小结构，但也会重新出现碎片和噪点。应根据深度置信度、曲率和区域大小进行自适应平滑，而不是简单把所有平滑参数降到零。

### 8. 多视角重建

单张照片只能恢复相机可见表面的 2.5D 深度，无法得到被遮挡区域和背面。若未来需要真正完整的高精度点云，仍需多角度照片、摄影测量或多视图深度融合。该路线的拍摄成本更高，暂不作为当前版本的优先工作。
